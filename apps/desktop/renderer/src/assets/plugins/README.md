# Plugin assets

- `prompt-wallpaper.webp`: OpenAI artwork from `https://learn.chatgpt.com/images/codex/codex-wallpaper-1.webp`. Its upstream rights remain with OpenAI; Cypheria uses it only in the Codex plugin surface.
